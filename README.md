# ElementalCube — площадка для проверки ощущений

Нативный прототип для **iPhone и iPad** на SwiftUI + MetalKit. Mac-приложение использует тот же игровой и графический код. Один берег, ящик, водоём с пологими каменными выходами, центральная опора, три кристалла и флаг.

## Управление

- Удерживайте **← / →**, чтобы катиться. В воде эти кнопки дают горизонтальный гребок.
- Короткое касание кнопки прыжка — прыжок вверх. Существующая инерция сохраняется.
- Оттяните кнопку и отпустите для направленного прыжка. По умолчанию вектор противоположен оттягиванию. В настройках можно выбрать прямое прицеливание.
- Стрелка и пунктирная дуга используют ту же начальную скорость, что физический исполнитель, включая текущую скорость куба.
- В воде кнопка прыжка даёт толчок к поверхности; опора на суше для него не требуется. В воздухе второго прыжка нет.
- Морозное дыхание работает у воды, стоит 30 энергии и создаёт наст на **25 секунд**. Если куб уже в воде, вокруг него остаётся отверстие для выхода.
- На Mac: **← / →** или **A / D** — движение; **пробел** — прыжок; **F** — дыхание; **R** — новая попытка; **Esc** — пауза.

## Что можно почувствовать

Куб — объёмная округлая сетка с отдельными геометрическими прядями, глазами и мимикой. Он моргает, смотрит в сторону действия, сосредотачивается перед прыжком, реагирует на воду, радуется кристаллам, встряхивается после намокания и засыпает от бездействия. Намокшая шерсть темнеет, слипается, становится короче и тяжелее; с неё стекают капли.

Box2D 3.1.1 считает твёрдые тела, реальные вращения, импульсы, столкновения и трение. Трава гасит движение, камень жёстче, на льду куб скользит. Сила и поверхность посадки меняют сжатие, выражение лица, частицы и небольшую встряску камеры. Вода поддерживает куб и ящик, тормозит их, реагирует волнами на вход в воду и толчки.

## Запуск на Mac

```sh
./scripts/run-mac.sh
```

Скрипт локально собирает `build/ElementalCube.app`, подписывает временной подписью и открывает приложение. Нужен установленный Xcode; внешние пакеты при сборке не скачиваются.

## iPhone / iPad

Откройте **ElementalCube.xcodeproj**, выберите схему **ElementalCube-iOS** и симулятор или своё устройство. Для физического устройства выберите свою Team в Signing & Capabilities. Поддерживаются портретная и обе горизонтальные ориентации; поворот отменяет незавершённый жест.

Проект уже сгенерирован. Если изменён `project.yml`, обновите его локально:

```sh
xcodegen generate
```

Сборка симулятора из терминала:

```sh
xcodebuild -project ElementalCube.xcodeproj -scheme ElementalCube-iOS \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/ios CODE_SIGNING_ALLOWED=NO build
```

## Проверки

```sh
swift test
```

Проверяются столкновения, запрет воздушного прыжка, плавучесть, выход из воды без льда, отверстие при замораживании вокруг погружённого куба, время таяния, вращение при качении, разница скольжения, жёсткость посадки, направления жеста, совпадение предпросмотра и исполненного импульса, воспроизводимость и прохождение карты реальными прыжками.

## Границы прототипа

Вода пока представляет собой пружинную поверхность с плавучестью и сопротивлением, а не объёмный решатель жидкости. Шерсть использует геометрические пряди и процедурную деформацию; полноценного решателя связей мокрых волос ещё нет. Скелет травм, обучение, эволюция, арена, сервер и сохранения не реализованы. Качество и FPS на физическом iPhone требуют отдельного измерения.

Исходники остаются локальными. CI/CD, облачной публикации и сетевых сервисов нет.

## Состав

- `Sources/ElementalCore` — физический мир, материалы, вода, события, прицеливание.
- `Sources/CPhysics` — узкая C-обёртка над Box2D.
- `Sources/ElementalCube` — общий Metal-рендер, геометрия, SwiftUI, адаптеры ввода.
- `Vendor/Box2D` — закреплённый исходный релиз 3.1.1; лицензия MIT.
- `Tests/ElementalCoreTests` — локальные проверки физики и управления.
- `project.yml` — описание iOS-проекта для XcodeGen.

`Shaders.metal.txt` намеренно копируется как текст и компилируется через Metal API при запуске: сборка не требует отдельно установленного Metal Toolchain.
