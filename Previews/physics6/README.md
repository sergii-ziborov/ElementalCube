# ElementalCube — альфа 6

Нативные снимки приложения 0.1.0 (6), без изменения размера и дорисовки. Для Apple удалён только полностью непрозрачный альфаканал PNG; RGB-пиксели сохранены.

| Снимок | Сцена |
| --- | --- |
| [iPhone: морозное касание](iphone-ice.png) | Первая ледяная опора возникает до погружения; название навыка открывает описание |
| [iPhone: ящик и вода](iphone-crate.png) | Поворот и плавучесть ящика, волна, подвижные секции моста |
| [iPhone: мост под нагрузкой](iphone-bridge.png) | Каменная форма прогибает доски; видны закрытые нижние грани и тросы |
| [iPhone: описание способности](iphone-ability.png) | Информационная панель без переключателя экипировки |
| [iPad Pro 13″](ipad-13-ice.png) | Та же сцена и сенсорное управление на планшете |

iPhone 16 Pro / iOS Simulator 26.5: 1206 × 2622. iPad Pro 13″ M4: 2064 × 2752. Для воспроизводимости используются локальные QA-аргументы `--preview-physics-ice`, `--preview-physics-crate`, `--preview-physics-bridge` и `--preview-ability`. Обычный запуск не включает эти сцены. Отдельно проверена сцена с включённым временем: жидкость, ящик и доски продолжают двигаться и успокаиваются.
