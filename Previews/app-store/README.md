# Скриншоты ElementalCube для карточки Apple

Снимки работающей альфы **0.1.0** из симуляторов. Тестовые сцены показывают лёд и шерсть после воды. PNG сохраняются в исходном разрешении экрана, без альфа-канала.

| Файл | Раздел App Store Connect | Размер | Сборка | Сцена |
| --- | --- | --- | --- | --- |
| [iphone-63-ice.png](iphone-63-ice.png) | iPhone с Dynamic Island, средний дисплей (6.3″) | 2622 × 1206 | 3 | Ледяной наст |
| [iphone-63-wet.png](iphone-63-wet.png) | iPhone с Dynamic Island, средний дисплей (6.3″) | 2622 × 1206 | 3 | Мокрая шерсть на берегу |
| [iphone-69-ice.png](iphone-69-ice.png) | iPhone с Dynamic Island, большой дисплей (6.9″) | 1320 × 2868 | 2 | Ледяной наст |
| [iphone-69-wet.png](iphone-69-wet.png) | iPhone с Dynamic Island, большой дисплей (6.9″) | 1320 × 2868 | 2 | Мокрая шерсть на берегу |
| [ipad-13-ice.png](ipad-13-ice.png) | iPad 13″ | 2064 × 2752 | 2 | Ледяной наст |

Для обязательных разделов Apple используйте набор iPhone со средним дисплеем и снимок iPad 13″. Снимки для большого iPhone доступны дополнительно.

На странице файла выберите **Download raw file**, чтобы получить оригинальный PNG. Эти размеры соответствуют [спецификации Apple](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/).
