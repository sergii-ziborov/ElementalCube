# ElementalCube — снимки альфы 4

Работающая сборка **0.1.0 (4)**, iOS Simulator 26.5. Пять форм, здоровье/мана и новый интерфейс пассивных способностей. Это захваты экрана приложения с воспроизводимыми тестовыми сценами; изображения не дорисованы. PNG в исходном размере, RGB без альфа-канала.

iPhone — 16 Pro (6.3″), iPad — Pro 11″ / 13″ (M4). На странице файла выберите **Download raw file**, чтобы получить оригинал. Пять снимков iPhone со стихиями и снимок iPad 13″ загружены в обе локализации карточки Apple 15 октября 2026; все 12 ассетов получили состояние `COMPLETE`. Набор сборок 2/3 для других размеров сохранён в [app-store](../app-store); механики и интерфейс в нём относятся к прежней альфе.

Для повторения используйте аргументы запуска `--preview-ice`, `--preview-water`, `--preview-air`, `--preview-stone`, `--preview-fire`, `--preview-ability`, `--preview-forms` и `--preview-wet`. Они включают локальную тестовую сцену с остановленным временем; обычный запуск начинает игру на берегу.
