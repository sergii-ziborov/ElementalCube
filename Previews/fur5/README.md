# Мягкая шерсть — сборка 0.1.0 (5)

Снимки работающего приложения на iPhone 16 Pro, iOS Simulator 26.5, 1206 × 2622. Одинаковые положение, масштаб камеры и сцена позволяют сравнить сухую и мокрую шерсть. Изображения не дорисованы.

| Сухой подшёрсток | Мокрая прилегающая шерсть |
| --- | --- |
| ![Сухая шерсть](iphone-dry.png) | ![Мокрая шерсть](iphone-wet.png) |

Локальные аргументы запуска: `--preview-fur-dry`, `--preview-fur-wet`, `--preview-fur-wind`. Эти сцены останавливают физику после подготовки. `--preview-fur-live` оставляет время, ветер, дыхание и управление включёнными. Обычный запуск открывает игру с сохранёнными настройками.

Это новый вид после [альфы 4](../alpha4), которая сохранена отдельно. [Как устроена шерсть](../../docs/FUR.md).
