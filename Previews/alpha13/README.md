# Альфа 13 — нативные снимки

Четыре iPhone 16 Pro (1206 × 2622) и два iPad Pro 13″ M4 (2064 × 2752). Оригинальные кадры Release-приложения из XCTest; только преобразованы в RGB PNG для Apple без изменения размера, обрезки и подрисовки интерфейса. Сцены для проверки используют отдельный временный профиль, пользовательские сохранения не меняются.

- `iphone-fire-tree.png` — личное дерево Огонька, бесплатная пассивка и первая ветка.
- `iphone-hot-core.png` — настоящее сравнение здоровья 100% → 85%, цена и изучение.
- `iphone-water-tree.png` — продолжение водной ветки, условия следующих узлов.
- `iphone-living-water.png` — завершающее лечение, числа и заблокированное изучение.
- `ipad-13-fire-tree.png`, `ipad-13-hot-core.png` — те же работающие экраны на iPad.

`skill-emblems.png` — отдельная контактная таблица 20 игровых иллюстраций для просмотра в репозитории, не снимок интерфейса и не материал карточки Apple. [Происхождение и промпты](../../docs/SKILL-ART.md).
