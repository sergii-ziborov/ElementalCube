# ElementalCube alpha 8 — нативные снимки

Release-сборка iOS, iPhone 16 Pro (1206 × 2622) и iPad Pro 11″ M4 (1668 × 2420). Снимки сделаны через simctl в исходном разрешении. Удалён только неиспользуемый альфа-канал; RGB, размеры и содержимое не менялись.

- `iphone-skills.png`: дерево Льдинки.
- `iphone-fire-skills.png`: огненная ветвь.
- `iphone-gesture.png`: направленный прыжок и пунктир.
- `iphone-ice.png`: морозное касание и физический мост.
- `ipad-11-skills.png`, `ipad-11-fire-skills.png`: инвентарь на iPad, нижние уровни доступны прокруткой.

Сценарии используют реальные параметры симуляции и стандартный стартовый инвентарь; прогресс игрока не меняется. Четыре снимка iPhone используются в карточке Apple; прежние снимки iPad 13″ находятся в `Previews/gestures7`.
