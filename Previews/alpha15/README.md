# Нативные снимки альфы 15

Оригинальные снимки Release-приложения через XCTest на iPhone 16 Pro (1206 × 2622) и iPad Pro 13″ M4 (2064 × 2752), iOS 26.5. Изолированные QA-профили с подготовленным прогрессом; снимки не являются прохождением человеком всей кампании. Мир, физические обломки, портреты, рисунки и статусы получены из настоящего приложения. RGBA→RGB для Apple; размеры и каждый RGB-пиксель сохранены. Локальные источники и сопоставление находятся в `build/alpha15/screenshot-sources.json`.
