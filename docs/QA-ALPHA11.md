# Проверка альфы 11 — 15 октября 2026

Проверки управления, главного экрана, коллекции, эволюции, мерджа и трёх карт наследуют [проверенный объём обновления 10](QA-ALPHA10.md). Сборка 10 была подготовлена локально, но не загружена в Apple: до выпуска получены новые правки материалов.

## Материалы

Вода без шерсти, гладкая и каплевидная. Огонь покрыт изогнутыми язычками на всех гранях; плоская нижняя полоса и рисованный след отменены. Камень — объёмный квадратный метеорит с геометрическими кратерами, без сетки трещин. Воздух состоит из лёгкого ядра и отдельных струй. По отзыву владельца у Льдинки сохранён прежний мягкий Canvas-портрет; шерсть дополнена на верхней и боковых гранях. Неудачный шумный Metal-предпросмотр льда не используется.

## Проверки

Ранний полный прогон: 84 теста ядра, 0 ошибок, 151,95 с (`build/alpha11-core.log`). После уточнения горения добавлены четыре физических проверки контакта с горючей поверхностью, запрета следа в воздухе/на камне, обугливания сухого моста, конечной воды и здоровья при кипении и сохранения массы/суммарного импульса при конвекции: 4 теста, 0 ошибок, 0,96 с (`build/alpha11-surface-final.log`). Финальный полный прогон после ограничения кипения реальным контактом: **89 тестов, 0 ошибок**, 147,97 с (`build/alpha11-core-contact-final.log`).

Полный нативный прогон iPhone 16 Pro Release: 10 тестов, 0 ошибок, 146,75 с, TEST SUCCEEDED (`build/alpha11-ui-final.xcresult`). Пройдены жесты, навыки, экипировка, пять анимированных портретов, выбор первого друга, оплата последующих, три карты, эволюция и реальный мердж.

iPad Pro 13″ M4 Release: 4 теста, 0 ошибок, 71,03 с, TEST SUCCEEDED (`build/alpha11-ipad.xcresult`): все сценарии главного экрана и анимация пяти портретов. После последних правок материалов дополнительно пройдены 5 тестов iPhone: **0 ошибок**, 78,20 с (`build/alpha11-reviewed-ui.xcresult`); повтор портретов — 2 теста без ошибок, 24,15 с (`build/alpha11-material-final.xcresult`). После исправления камеры портрета — 1 тест без ошибок, 16,87 с (`build/alpha11-portrait-camera.xcresult`); iPad — 1 тест без ошибок, 17,60 с (`build/alpha11-ipad-materials.xcresult`).

Mac Release успешно собран (`build/alpha11-mac-release-final.log`). Приложение проверялось после перезапуска из нового бинарного файла: прежний процесс не считается проверкой новой отрисовки. Версия приложения теперь берётся из project.yml и отображается в интерфейсе.

Нативная проверка кипения в iPhone-приложении: **1 тест, 0 ошибок**, 8,88 с (`build/alpha11-boiling.xcresult`): огненная форма находится в воде, испарение работает, газовые пузырьки существуют, мана остаётся 100.

Камера портрета теперь смотрит сверху и учитывает глубину по всем осям; тень лежит под телом, не отсекая нижнюю грань. У воды отменены боковины на внутренних границах плотности. Проверка после последней графической правки: 1 тест без ошибок, 6,34 с, TEST SUCCEEDED (`build/alpha11-boiling-surface.xcresult`).

Нативные снимки и запись анимации пересняты для [альфы 11](../Previews/alpha11). Публикация подтверждается отдельно в [TestFlight](TESTFLIGHT.md).

Физический iPhone/iPad пользователя не подключён. Батарея, нагрев и частота кадров требуют проверки на устройстве. Жидкость остаётся игровой 2D-моделью с объёмным изображением; точная термодинамика и свободные ледяные обломки не моделируются.
