# Проверка альфы 4 — 14 октября 2026

Версия 0.1.0, сборка 4, Bundle ID `com.weavatrix.elementalcube`.

- `swift test -c release --jobs 2`: **46 проверок, 0 ошибок**. Проверены пять форм, подводный проход и выход камня на берег, холод во всех направлениях, выход из воды после заморозки, горение и удаление ящика, осушение чаши, остановка испарения при смерти, здоровье/мана, масса мокрой шерсти, пряди и ветер, управление и прохождение карты.
- iOS Simulator: сборка успешна; просмотрены пять форм на iPhone 16 Pro в альбомной ориентации и мокрая шерсть на iPad Pro 11″ в портретной. Отдельно просмотрены панели выбора формы и экипировки способности. [Снимки](../Previews/alpha4).
- Mac: release-сборка обновлена в `build/ElementalCube.app`, локальная подпись проверена.
- iPhone/iPad: Release-архив и IPA экспортированы с Apple Distribution. Проверены подпись, версия 4, обе семьи устройств `[1, 2]`, iOS 16.0+, `get-task-allow = false`.
- Тексты русской и английской карточки прошли локальную проверку ограничений полей.

Подписанная IPA: `build/alpha4/Export/ElementalCube-iOS.ipa` (игнорируется Git).

SHA-256: `7715732122026c2cceced993de2e2e572493cec0a31a1888ccbfd42f662b2633`.

При последней проверке API App Store Connect карточка для Bundle ID отсутствует. Поэтому сборка **не загружена и не доступна в TestFlight**. Загрузка, обработка Apple и доступность группе тестеров — отдельные последующие состояния.

Физический iPhone/iPad в этой проверке не использовался: FPS, нагрев и вибрацию на устройстве ещё предстоит оценить. Игровая физика — 2,5D; вода имеет конечный объём и гидростатический уровень, лёд закреплён в сетке, пряди используют направляющие с ограничениями длины. Полноценная трёхмерная жидкость и столкновения всех волос между собой не реализованы.
