# ElementalCube — alpha 0.1.0 (1)

Нативная тестовая площадка для iPhone и iPad. Сборка включает качение, прыжки с предпросмотром траектории, плавание и выход из воды, мокрую шерсть, морозное дыхание, физический ящик и разную реакцию на посадку.

## Локальная сборка и загрузка

Используется стабильный `/Applications/Xcode.app`. Скрипты работают вручную; CI/CD нет.

Ключ App Store Connect хранится вне репозитория. Переменные `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_PATH` можно задать в окружении или в локальном `~/.private_keys/appstoreconnect.env`. Путь к другому файлу задаётся через `ASC_ENV_FILE`. Содержимое ключа не выводится.

```sh
./scripts/testflight.sh prepare
./scripts/testflight.sh validate
./scripts/testflight.sh upload
python3 scripts/asc.py status
```

Для следующей сборки передайте уникальный номер: `ELEMENTAL_BUILD_NUMBER=2 ./scripts/testflight.sh prepare`.

Архив, подписанная IPA и журналы находятся в игнорируемой папке `build/testflight`.

Перед первой загрузкой нужна карточка приложения в App Store Connect:

- Platform: iOS (включает iPad).
- Name: ElementalCube.
- Primary language: Russian.
- Bundle ID: `com.weavatrix.elementalcube`.
- SKU: `ElementalCube-iOS`.
- User access: Full Access.

API Apple не создаёт карточки приложений; этот шаг выполняется на сайте App Store Connect. Подготовка подписи регистрирует Bundle ID и использует действующий локальный сертификат Apple Distribution.

Успешная загрузка ещё не означает доступность в TestFlight. Сначала Apple обрабатывает сборку; затем её нужно добавить в группу тестирования. Первую сборку для внешних тестеров Apple проверяет отдельно.

## Что проверить на устройствах

- Прыжки вправо, влево и вверх, совпадение дуги с полётом.
- Выход из воды кнопками движения и толчком без перезапуска карты.
- Замораживание из воды: отверстие для куба и таяние через 25 секунд.
- Мягкая посадка на траву, скольжение по льду и качение на камне.
- Одновременное движение и прыжок, портретная/горизонтальная ориентация.
- Уход в фон и продолжение игры без сохранённого нажатия.

Обучение куба, эволюция, арена и сетевые функции в этой альфе ещё не реализованы.
