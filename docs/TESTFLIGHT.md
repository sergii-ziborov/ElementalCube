# ElementalCube — alpha 0.1.0 (8)

Новый вид личного дерева навыков и обычный прыжок коротким тапом по самому кубику. Перетягивание остаётся направленным прыжком, касание карты — движением. Номер установленной сборки виден под названием игры и в настройках.

## Статус — 15 октября 2026

Сборка **0.1.0 (8)** загружена и обработана Apple: **VALID**. Build ID `fd7ea0a0-866f-445c-b917-7af1aa3fee85`.

- **ElementalCube Internal**: сборка 8, **IN_BETA_TESTING**. Подтверждено членство сборки в группе и прямое назначение существующему внутреннему тестеру. Новые приглашения не отправлялись.
- **ElementalCube Alpha**: сборка 8 заменила 7 в этой внешней группе. Прежние внутренние сборки остаются доступными.
- **Внешняя проверка**: у 8 **READY_FOR_BETA_SUBMISSION**. Запрос проверки получил `422 ENTITY_UNPROCESSABLE.ANOTHER_BUILD_IN_REVIEW`: Apple уже проверяет сборку 4. Отправку 8 нужно повторить после завершения проверки 4. Текущая проверка не отменялась, сборки не истекали.

[Карточка Apple](https://appstoreconnect.apple.com/apps/6822921592/testflight) · [Публичная ссылка внешней группы](https://testflight.apple.com/join/snm99FQh). Добавление сборки во внешнюю группу требует последующего одобрения Apple для внешней установки.

## Обновление на устройстве

В TestFlight откройте ElementalCube и обновите до **0.1.0 (8)**. Для выбора доступной сборки используйте **Предыдущие сборки → 0.1.0 → 8 → Установить**. [Инструкция Apple](https://testflight.apple.com/) описывает выбор Previous Builds.

После запуска под названием игры отображается **АЛЬФА · 8**. Кнопка стихии открывает инвентарь: цветное дерево с круглыми узлами; короткий тап по кубику прыгает вверх. Доступность в группе не подтверждает фактическую установку на телефоне.
