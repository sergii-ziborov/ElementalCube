# Разработка ElementalCube

SwiftUI + MetalKit/Metal, Box2D 3.1.1 и локальные XCTest. Общий игровой код используется на iPhone, iPad и Mac.

## Запуск на Mac

```sh
./scripts/run-mac.sh
```

Скрипт локально собирает `build/ElementalCube.app`, подписывает временной подписью и открывает приложение. Нужен установленный Xcode; внешние пакеты при сборке не скачиваются.

## iPhone / iPad

Откройте **ElementalCube.xcodeproj**, выберите схему **ElementalCube-iOS** и симулятор или своё устройство. Для физического устройства выберите свою Team в Signing & Capabilities. Поддерживаются портретная и обе горизонтальные ориентации; поворот отменяет незавершённый жест.

Проект уже сгенерирован. Если изменён `project.yml`, обновите его локально:

```sh
xcodegen generate
```

Сборка симулятора из терминала:

```sh
xcodebuild -project ElementalCube.xcodeproj -scheme ElementalCube-iOS \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/ios CODE_SIGNING_ALLOWED=NO build
```

## Проверки

Проверки управления дополнительно охватывают прямые жесты во всех квадрантах, монотонную силу и предел навыка, сохранение точки движения, hit-testing в обеих ориентациях, независимость инвентарей и изменение физических параметров навыками/снаряжением. Все проверки выполняются локально.

Альфа для iPhone/iPad собирается и загружается вручную: [TestFlight](TESTFLIGHT.md). Политика конфиденциальности: [PRIVACY.md](PRIVACY.md).

```sh
swift test -c release --jobs 2
```

Проверяются столкновения и прохождение карты реальными прыжками, управление и камера, свойства пяти форм, подводный проход, постепенное замораживание вверх/вниз, выход из воды после заморозки, таяние и трение, горение дерева, сохранение объёма воды при замерзании и испарении, цена испарения в здоровье, истощение маны, корни и длины прядей, реакция шерсти на ветер и воду. Release нужен для реалистичной скорости расчёта сотен прядей; debug также поддерживается, но заметно медленнее.

## Состав

- `Sources/ElementalCore` — физический мир, пять форм, материалы, вода, пряди, события, прицеливание.
- `LiquidSolver.swift` — частицы PIC/FLIP, сетка MAC, совместная проекция давления жидкости и тел.
- `WaterField.swift` — консервативный переход вода/лёд, первая опора при касании и постепенный рост холода.
- `Hydrodynamics.swift` — повёрнутые границы тел и секции подвесного моста; [физика сборки 6](PHYSICS.md).
- `FurPhysics.swift` — Verlet-интеграция и ограничения корней/сегментов на шести гранях.
- [Шерсть сборки 5](FUR.md) — короткий подшёрсток в Metal и изогнутые пучки по физическим направляющим; [снимки для сравнения](../Previews/fur5).
- `Sources/CPhysics` — узкая C-обёртка над Box2D.
- `Sources/ElementalCube` — общий Metal-рендер, геометрия, SwiftUI, адаптеры ввода.
- `Vendor/Box2D` — закреплённый исходный релиз 3.1.1; лицензия MIT.
- `Tests/ElementalCoreTests` — локальные проверки физики и управления.
- `project.yml` — описание iOS-проекта для XcodeGen.

`Shaders.metal.txt` намеренно копируется как текст и компилируется через Metal API при запуске: сборка не требует отдельно установленного Metal Toolchain.

## Нативные жесты: локальные UI-тесты

Схема содержит `ElementalCube-UITests`. Тесты нажимают на карту, меняют направление, тянут самого куба, поворачивают iPhone, изучают навык и надевают оберег. Их можно запустить в Test Navigator. В терминале используйте `build-for-testing`, затем `test-without-building -xctestrun …` с конкретным симулятором; это также избегает повторного разрешения локального пакета после тестов в Xcode 27.

Локальные сцены для снимков: `--preview-gesture`, `--preview-skills`, `--preview-equipment`, `--preview-summit`, `--preview-cave`, `--preview-physics-ice`. Они отключены при обычном запуске. `--ui-testing` создаёт предсказуемый личный инвентарь только внутри запущенного тестом приложения.

## Проверка интерфейса выпуска

Для тестирования жестов и инвентаря используйте конфигурацию Release: неоптимизированная физика в симуляторе может заметно отставать от реального времени. Короткий тап распознаётся по системному монотонному времени, а не приостановленному времени симуляции.

```sh
xcodebuild -project ElementalCube.xcodeproj -scheme ElementalCube-iOS -configuration Release -destination 'platform=iOS Simulator,name=ElementalCube iPhone' -parallel-testing-enabled NO test
```

Номер сборки отображается из `CFBundleVersion` в шапке и настройках. Метаданные и подпись IPA проверяются перед ручной загрузкой. CI/CD не используется.

## Спецификация и наследование 14

[Исходник v2](SPECIFICATION-V2.txt) сохранён без изменений; [аудит](SPEC-AUDIT.md) перечисляет все 30 задач и границы текущей реализации. `CreatureForm.swift` задаёт текущую морфологию и явные реакции; `Inheritance.swift` — паспорта, точный отбор, фиксаторы и provenance. `ReleaseManifest.current` сохраняет версии локальных правил в исходе рождения. Отсутствующие policy/observation schema не обозначаются выдуманными версиями. `AdventureState` хранит архив и commit одним снимком.

Локальная сцена `--preview-metamorphosis --ui-testing` открывает подготовленный пример Льдинка → Парик с одним фиксатором, не изменяя обычное сохранение. Она использует настоящий алгоритм рождения и случайный отбор, не постановочный исход. `MetamorphosisTests` проверяет отмену, закрепление, отчёт, физические свойства потомка и сохранность донора. Тестовый `LegacyHybridFixture` воспроизводит уже выпущенный старый формат для проверки миграции; новый игровой код его не вызывает.


Навыки сборки 13: каталог и числовые сравнения находятся в `SkillCatalog.swift`, эффекты применяются через `Simulation.applySkills`. Иллюстрации упакованы как папка `SkillArt` в обе платформы; [промпты](SKILL-ART.md). Для проверки вертикального жеста локальный `--ui-testing --test-calm` убирает только внешний ветер, не меняя допуск теста. На Mac маленькие портреты рисуются тем же Metal-кодом в повторно используемые текстуры и компонуются SwiftUI; iOS использует MTKView напрямую.
